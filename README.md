# Tripleten web_project_homeland

# De Pátria para Pátria

## Descrição do projeto

Este projeto é uma página web responsiva que apresenta as cidades natais de funcionários da TripleTen. O objetivo é mostrar histórias e imagens de diferentes lugares do mundo através de um layout adaptável para diferentes tamanhos de tela.

## Tecnologias e técnicas utilizadas

- HTML5 para estruturação da página;
- CSS3 para estilização;
- Metodologia BEM para organização das classes;
- Flexbox para alinhamento dos elementos;
- Media queries para criar um layout responsivo;
- Figma como referência para implementação do design;
- Fontes locais utilizando @font-face.
